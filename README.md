# 🐞 Intelligent Bug Diagnosis Platform

## 📌 Project Overview

The Intelligent Bug Diagnosis Platform is a Python-based application that analyzes software bug reports, identifies potential root causes, detects related defects, and recommends possible fixes.

The platform provides an interactive interface for submitting bugs and analyzing defect patterns through a dashboard.

## 🎯 Objectives

- Automate software bug analysis.
- Identify exception types and failure points.
- Determine potential root causes.
- Detect duplicate or related bugs.
- Recommend possible solutions.
- Analyze defect patterns using visual dashboards.

## ✨ Features

- Bug submission with title, description, stack trace, and error logs.
- Automated bug triage and severity classification.
- Log and exception analysis.
- Root cause analysis.
- Duplicate and related bug detection.
- Remediation recommendations.
- Knowledge base growth support.
- Interactive defect analytics dashboard.

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Plotly
- FAISS
- Sentence Transformers
- Machine Learning and Natural Language Processing
